# Character Info: plan autorizado

Objetivo: detalle integrado en C, C e inventario simultáneos, lectura de staffs sin comandos.

1. Revalidar bundles públicos y documentar slots, exclusividad, catálogo, tooltip y cálculo nativo.
2. Helper: montar el host existente en C; adaptar únicamente el cierre mutuo C/inventario mediante interceptores del observable auditado. Conservar cierres nativos, foco y Escape; no interceptar teclas.
3. Separar rango nativo, base de energía, porcentaje del tooltip, adicionales y daño efectivo desconocido. No modificar equipo ni fórmulas del servidor.
4. Fixtures del bundle verificado: staffs en slot 0, reproducción del cálculo nativo y tooltip independiente. UI: teclado/botones, cierre/Escape, recreación, transacciones, identidad y viewport.
5. Documentar evidencia y límites; aumentar Helper, ejecutar release local completo y entregar ZIP/capturas/hashes.

Restricciones: preservar trabajo local y contrato v1; sin instalación, publicación o cuenta real. No requiere cambios de HUB si su capability.actions vigente sigue funcionando. Una actualización futura del cliente deshabilita el adaptador hasta revalidación.

Revisión: el slot de la cuenta del usuario y el daño efectivo del servidor permanecen desconocidos. Las demos no prueban una partida real. El cliente permite ambos slots, pero Wizardry solo lee 1; el tooltip utiliza otra ruta con tratamiento especial de Archangel.
